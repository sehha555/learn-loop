# 整體 UI 重新設計 — 設計（2026-09-28）

## 目標

使用者 9/28 以 Derive 為目標，並說「現在有點亂」。現在的 app 是四個平行分頁（題目／概念／考試／畫布），畫布排最後，上線一週零使用。
這一輪把外殼換成「書架 → 資料夾 → 材料 → 畫布」：打開 app 先看是哪科，點進材料就是紙，AI 的東西都從紙上長出來。

終點仍是取代 GoodNotes（見 [[project-wiki-direction]]）；頁面管理這塊直接照抄 GoodNotes，不自己發明。

設計畫布（含可以點的講解原型）：https://claude.ai/artifact/MJt3NtYqomqEyZjLE48swS
- 資料夾頁定案：B 版（左清單、右地圖）
- 講解定案：原型那張（浮動／固定可切換、慣用手反邊）

## 1. 整體結構

```
第一次打開 → 慣用手問卷（左／右）
書架
└── 資料夾（可以無限往下開，照 GoodNotes）
    ├── 資料夾頁 = 左邊清單 + 右邊知識地圖
    └── 材料（PDF 講義，或空白筆記本）
        └── 畫布
設定：慣用手、考試週
```

原本四個分頁全部拿掉：

| 原本 | 新位置 |
|---|---|
| 題目 | 印在講義上，不另外列 |
| 概念 | 講解裡的名詞連結跳過去的概念頁 |
| 考試 | 科目資料夾上的倒數＋設定裡的考試週 |
| 畫布 | 主畫面 |

## 2. 書架與資料夾

- 資料夾可以無限層（使用者選的，照 GoodNotes）
- **資料夾頁**：左邊是這個資料夾的內容清單（子資料夾、材料），右邊是知識地圖
- **地圖範圍＝這個資料夾以下所有材料的概念**。因此每個概念要記它來自哪份材料、哪一頁（圈選／批改時寫入）
- 地圖視覺沿用 8/23、8/28 定案規格（膠囊、不規則散佈、漂浮、紅徽章＝栽過幾次、「只看栽過的」開關）：設計畫布 01ccc2b3 第三頁
- **舊資料**：之前截圖累積的題目與概念沒有來源材料，只出現在書架最上層的總地圖，不屬於任何資料夾。之後要整理再加手動搬移
- **匯入 PDF**：書架／資料夾頁的「＋ 匯入」（從檔案 app 挑）＋ 從別的 app 分享進來（擴充現有分享浮層）

### 考試

- 只記時間，不記範圍（使用者：範圍常常不是學生能控制的）
- 設定裡設**考試週**（日期區間，全部共用）
- **科目資料夾**（書架最上層那一層）可以設考試名稱＋日期，資料夾頁上方顯示「期中考還有 N 天」。子資料夾不能設，避免同一科兩個倒數

## 3. 畫布

### 頁面（照抄 GoodNotes）

- 一份材料 = 一串**固定大小**的頁：講義頁＋使用者插入的空白頁
- 上下連續捲，頁與頁之間有分隔與頁碼
- 講義頁上可以直接寫
- 工具列「＋」：加在這頁後面，空白或橫線
- 工具列「總覽」：縮圖格子，拖拉排序、刪除、複製
- **拿掉**現在「寫到底紙自己變長」的行為（改成固定頁，寫不下就加頁）
- 舊的畫布頁（9/17 起在畫布分頁寫的）搬進書架最上層一本「舊畫布」筆記本

### 工具列

沿用現在的紙頂細工具列（筆×3 色＋粗細滑桿、螢光筆、橡皮擦兩模式、套索、圖形、復原／重做），加上「＋ 加頁」「總覽」。

### 圈選之後

```
圈選完 → 旁邊跳出 [解釋] [批改] [打字問…]
```

不讓 AI 猜使用者要什麼：同一段手寫可能是要批改，也可能是要解釋概念。多點一下只要半秒，猜錯要多等一次 AI（10–20 秒）。

## 4. 講解卡片

```
講解卡片
├── 位置：慣用手的反邊（右撇子放左、左撇子放右）
├── 兩種模式，標題列一顆鈕切換，app 記得上次選的
│   ├── 浮動（預設）：可拖、可縮成紙上的記號
│   └── 固定：側邊一欄，紙讓出位置
├── 內文
│   ├── 名詞連結（底線）→ 概念頁 →「在地圖上看」→ 地圖上那個點
│   └── 長按一句 → 追問就地展開在那句底下（縮排、可收起、可以一層層往下）
├── 解題步驟：先藏著，按「下一步」一步步出現
├── 釘到紙上 → 變成紙上可收可展的卡片
└── 底部輸入框：不想圈的時候直接打字問
```

- 側邊欄**只放講解**。老毛病改成當下提醒、筆記就是紙本身＋概念頁、題目就在講義上
- 名詞連結：AI 回答時標出用到的概念名；已有概念頁就連過去，沒有就點了當場建一個（沿用 8/28「概念是唯一節點」）
- 追問用長按觸發，因為卡片上是一般文字不是手寫
- 追問的設計是為了解決傳統對話 UI 的痛點：追問接在最後、越拉越長，回頭找原題要滑很久。就地展開讓原題講解永遠在原位

## 5. 批改與老毛病

```
[批改] → 講解卡片上方多一條批改結果
├── 對 → 「正確」，紙上記號變綠
└── 錯 → 錯在第幾步 + 技巧標籤，記號變紅
    └── 犯過同樣的錯 → 紙上跳「第 N 次：…」
        └── 點提醒 → 列出之前錯的幾題，可以點回原頁
全科老毛病 → 資料夾頁地圖的紅徽章
```

- 技巧標籤沿用現有的 `Card.stuckSkill`；跨概念統計沿用 `ConceptLogic.allStuckSkills`（`ios/Shared/Store/ConceptLogic.swift`），按技巧數、跨概念數
- 紅色與綠色要同時靠亮度或圖示區分，不只靠顏色

## 6. 做的順序

每一塊另寫實作計畫、分開 commit，做完就裝 iPad 給使用者用，不一次全改完。

| 塊 | 內容 | 為什麼排這裡 |
|---|---|---|
| 1 | 書架＋資料夾（無限層）＋匯入 PDF＋ GoodNotes 式頁面＋慣用手問卷＋舊畫布搬家 | 先讓使用者真的能拿它寫這週的作業 |
| 2 | 圈選 →［解釋］［批改］［打字問］→ 講解卡片（浮動／固定、追問、名詞連結、步驟、釘上紙） | 第 1、2 塊做完就能取代 GoodNotes |
| 3 | 批改結果＋老毛病提醒 | 需要第 2 塊的圈選流程 |
| 4 | 資料夾頁的知識地圖＋考試週／考試倒數 | 地圖要有累積的概念資料才不會是空的 |
| 5 | 可以動的圖 | 最難，放最後 |

## 7. 這次不做（記著）

- 工具列的工程圖形：座標軸、球體、圓柱體等（使用者 9/28 提，之後再考慮）
- 考試延伸：排進度、複習、出題
- 舊題目手動整理進資料夾
- 整頁一次批改（Derive 式逐行勾叉，backlog 第 3 層）
- 圖形工具的方框合成一整筆（現在是四條邊，整筆擦只擦掉一邊）
